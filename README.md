# HLシグナルラボ — Hyperliquid 通知bot & 条件検証ツール

Hyperliquidの**全Perp銘柄（HIP-3ビルダー銘柄含む）**をブラウザ1枚で監視し、条件発火を**Discordに通知**、さらに過去のローソク足で**売買条件の成績を検証**できるツールです。サーバー不要・単一HTMLファイル。発注機能はありません（監視・検証のみ）。

## 機能

- **スキャナー**: 全銘柄の価格 / 15分・1時間・24時間変動 / Funding（時率＋年率換算）/ OI / 出来高を自動更新。HIP-3銘柄は金色タグ表示
- **アラート**: 急変動・24h変動・Funding過熱・OI急変・価格レベル到達の5種。対象は全銘柄/出来高上位N/指定リスト
- **Discord通知**: Webhookで発火をDiscordチャンネルへ送信（スマホのDiscordアプリでプッシュ受信）
- **バックテスト**: モメンタム / EMAクロス / ドンチャン / ボラティリティ・ブレイク / ボリンジャー / RSI（水準・50クロス）/ 連続足 / 出来高スパイク × 順張り/逆張り × SMAトレンドフィルタ × 損切り/利確 × 手数料込みで検証。全銘柄一括スキャン対応
- **プリセット**: BTC/ETHの「スキャルピング・デイトレード・スイング」別に、公開研究・検証記事で成績が報告されている型を15種内蔵

## GitHub Pagesで公開する手順（5分）

1. GitHubで新しいリポジトリを作成（例: `hl-signal-lab`）。PublicでもPrivateでも可（Pages無料公開はPublic）
2. `index.html` と `README.md` をアップロード（Add file → Upload files）
3. リポジトリの **Settings → Pages** を開く
4. **Source: Deploy from a branch / Branch: main / フォルダ: /(root)** を選んで Save
5. 数分後に `https://<ユーザー名>.github.io/hl-signal-lab/` で公開されます

以後の更新は `index.html` を上書きアップロードするだけです。

## Discord通知の設定

1. Discordで通知用サーバー（またはチャンネル）を用意
2. **サーバー設定 → 連携サービス → ウェブフック → 新しいウェブフック** → チャンネルを選び **URLをコピー**
3. ツールの**設定タブ**にURLを貼り付け → **テスト送信** で確認 → 「アラートをDiscordに送信する」をON
4. スマホのDiscordアプリで当該チャンネルの通知をONにすれば、外出先でもプッシュで受け取れます

> ⚠️ **Webhook URLは絶対にコードやリポジトリに書き込まないでください。** URLを知っている人は誰でもそのチャンネルに投稿できます。URLはブラウザのローカル保存のみで、GitHubには一切送信されません。

## 運用の前提と制約

- 監視は**このページを開いている間だけ**動きます。自宅PC（またはタブレット）でページを開いたままにし、通知はDiscord経由でスマホに受け取る運用を想定しています。ヘッダーの「画面スリープ防止」をONに
- ローソク足はHyperliquid APIの仕様で**各時間足あたり直近約5000本**まで（1時間足≈200日分）
- **HIP-3ビルダー銘柄の取引手数料は通常銘柄の約2倍**です。バックテストの手数料欄を上げて検証してください
- ビルダーDEXを多数有効化する場合はレート制限対策として**更新間隔15秒以上**を推奨
- 現物（スポット）は未対応
